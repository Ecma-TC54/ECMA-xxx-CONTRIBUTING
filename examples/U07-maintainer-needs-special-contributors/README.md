# U07: Maintainer wishes to find contributors for specific tasks

The project has grown to a size and user-base that makes the Maintainer realize they need help with new tasks that they are either uninterested or unskilled in performing.
Examples may include tasks or roles like project management, issue triage, community leadership or any of the others listed in [Appendix I].
The Maintainer is only interested in help with one or a few of these activities, and expects this to change if they find volunteers.
