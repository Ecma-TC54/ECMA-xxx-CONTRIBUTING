# U06: Maintainer realizes they need funding

The maintainer wishes to spend more time on their project, but realizes this is unlikely to happen through their current place of employment.
In an effort to build up resources, they start accepting different types of funding, and would like to communicate this opportunity to their users, including a link to an information page with details on how to fund the project, e.g. to a `FUNDING.yml` document ([GITHUB-2020]).

*GITHUB-2020: https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/displaying-a-sponsor-button-in-your-repository
