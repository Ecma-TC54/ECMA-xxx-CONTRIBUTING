# U03: The component project is considered DONE and is expected to receive no, or a bare minimum of further updates

The component solves a “closed problem” and the Maintainer claims there is nothing left to do.
No further documentation is needed, and no known bugs are left to fix.
This should affect the expected level of support among the project’s users, and therefore needs to be clearly communicated.

> “This project is done. No further development is expected.”

The Maintainer therefore flags the project as “DONE”.
