# U04: Sole remaining Maintainer becomes unresponsive for unknown reasons

Life happens, and a maintainer dies or otherwise “drops off the map”.
The project now has zero maintainers, and after a period it becomes clear that issues are left untouched and pull requests ignored.
Contributors to the project may try to reach out to the Maintainer, and fail.
No co-maintainers exist, so after an accepted minimum of due diligence (e.g. multiple attempts at contacting, spread over a few months), the ecosystem managers deem the project as abandoned, and put it up for adoption.
On CPAN, this is equivalent to the ecosystem managers assigning the project an “ADOPTME” status, though it’s probably useful to distinguish this from U02.
