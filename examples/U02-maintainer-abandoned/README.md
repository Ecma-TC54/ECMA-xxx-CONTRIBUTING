# U02: Last remaining Maintainer abandons their project

Maintainer writes a blog post that they aren’t interested in maintaining their OSS project any more, and have moved on to more interesting hobbies.
No co-maintainers or contributors have offered to take over the project within a reasonable time, and after a while, the Maintainer just leaves the project, and as a final act, they flag this project available for adoption.
(This is equivalent to the maintainer asking for an “ADOPTME” project state on CPAN).
